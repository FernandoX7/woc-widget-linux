# WoC Player Count 0.1.0 beta 1

This is the first packaged Linux beta of WoC Player Count.

The release includes checksummed Debian and AppImage downloads. Ubuntu and Pop!_OS are the initial
target distributions; other desktops are best effort while compatibility testing continues. The
COSMIC applet package and Flatpak are not included in this release.

Highlights include live realm and player information, truthful local history, `$WOC` market data,
community information, configurable alerts, and a cross-desktop tray application.

See the [installation guide](https://github.com/FernandoX7/woc-widget-linux/blob/main/docs/INSTALL.md)
for verification and installation instructions.
